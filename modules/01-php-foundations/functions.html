In one sentence

A function is a named, reusable block of code that takes inputs (parameters), does one job, and hands back a result (the return value).

☕A function is like a coffee machine. You put in beans and water (the inputs), press one button (call it), and get coffee back (the output). You don't need to know how it works inside every time you want a cup.

Why it matters

Write it once, use it everywhere

♻️

No copy-paste

Logic lives in one place. Fix a bug once and every caller gets the fix.

🏷️

Names explain intent

calculateTotal($cart) tells the reader what happens without making them read the maths.

🧪

Small pieces are testable

A function with clear inputs and outputs is easy to check: give it X, expect Y.

Step by step

Build your function skills

Each step adds one idea. Put declare(strict_types=1); at the top of your file so type mistakes are caught.

  1. Define and call a function

    Use the function keyword, a name, parentheses for parameters, and curly braces for the body. return sends a value back to whoever called it.

    
          <?php

          declare(strict_types=1);

          function greet(string $name): string
          {
              return "Hello, {$name}!";
          }

          echo greet('Ada');     // Hello, Ada!
          echo greet('Taylor');  // Hello, Taylor!

  2. Add types for safety

    Type declarations say what each parameter must be and what the function returns. A ? before a type means "this type or null". A union type like int|float accepts either. void means "returns nothing".

    
          function excerpt(string $body, int $length): string
          {
              return substr($body, 0, $length) . '…';
          }

          function findAuthor(int $id): ?string      // string or null
          {
              return $id === 1 ? 'Ada' : null;
          }

          function double(int|float $n): int|float   // union type
          {
              return $n * 2;
          }

          function logVisit(string $page): void      // returns nothing
          {
              echo "Visited {$page}" . PHP_EOL;
          }

          excerpt('Hello', '3');  // TypeError with strict_types: '3' is a string

  3. Defaults and named arguments

    A parameter with a default value becomes optional. Named arguments (PHP 8.0+) let you pass values by parameter name, so you can skip optional ones and make calls self-explanatory.

    
          function makePost(string $title, string $status = 'draft', bool $featured = false): array
          {
              return ['title' => $title, 'status' => $status, 'featured' => $featured];
          }

          makePost('Hello');                          // status: draft, featured: false
          makePost('Hello', 'published');             // positional

          makePost('Hello', featured: true);          // skip $status, set $featured by name
    💡 Named arguments beat mystery booleans

    Compare makePost('Hi', 'draft', true) with makePost('Hi', featured: true). The second one tells you what true means.

  4. Accept any number of arguments

    A variadic parameter (...$name) collects all remaining arguments into an array. The same ... also spreads an array back out into arguments.

    
          function tagList(string ...$tags): string
          {
              return implode(', ', $tags);
          }

          echo tagList('php', 'laravel', 'tips');   // php, laravel, tips

          $myTags = ['oop', 'testing'];
          echo tagList(...$myTags);                 // oop, testing

  5. Scope: functions live in their own bubble

    Variables created outside a function aren't visible inside it, and vice versa. That's called scope. Pass what the function needs as parameters and return what it produces.

    
          $siteName = 'Blueprint';

          function badTitle(): string
          {
              return $siteName;          // Warning: undefined variable $siteName
          }

          function goodTitle(string $siteName, string $page): string
          {
              return "{$page} · {$siteName}";
          }

          echo goodTitle($siteName, 'Home');   // Home · Blueprint

  6. Functions as values: closures and arrow functions

    A closure (anonymous function) is a function without a name that you can store in a variable or pass to another function. It borrows outside variables with use. An arrow function fn () => is a one-expression shortcut that captures outside variables automatically.

    
          $taxRate = 0.2;

          $withTax = function (float $price) use ($taxRate): float {
              return $price * (1 + $taxRate);
          };
          echo $withTax(100);          // 120

          $withTaxShort = fn (float $price): float => $price * (1 + $taxRate);

          $prices = [10, 20, 30];
          print_r(array_map($withTaxShort, $prices));  // [12, 24, 36]

          usort($prices, fn ($a, $b) => $b <=> $a);    // sort descending

    Passing a function into another function (like array_map or usort) is called a callback. You'll do this constantly in Laravel.

Common mistakes

Avoid this, do that

❌ Avoid

          function total($items) {
              echo array_sum($items);
          }

No types, and it prints instead of returning, so the caller can't reuse the result.

✅ Do

          function total(array $items): int|float
          {
              return array_sum($items);
          }

Typed, and it returns the value. The caller decides whether to print, store or compare it.

❌ Avoid

          function saveAndEmailAndLog(array $post): void
          {
              // 80 lines doing three jobs...
          }

A function that does many jobs is hard to name, test and reuse.

✅ Do

          savePost($post);
          emailSubscribers($post);
          logActivity('post.created');

One job per function. The calling code now reads like a to-do list.

💡 Pro tip: return early

Handle the edge case first and return, instead of wrapping the whole body in an if. For example: if ($items === []) { return 0; }. Flatter code is easier to read.

🏋️ Try it yourself
  1. Write readingTime(string $text, int $wordsPerMinute = 200): int that returns the minutes needed (round up with ceil).
  2. Call it once positionally and once with the named argument wordsPerMinute: 100.
  3. Write a variadic average(int|float ...$numbers): float.
  4. Use an arrow function with array_filter to keep only words longer than 4 letters from explode(' ', $sentence).
ℹ️ Where you'll see this in Laravel
  • Route closures: Route::get('/', function () { ... }) passes a closure as a callback (see Routing).
  • Helper functions such as view(), route(), config() and dd() are plain global functions.
  • Collections: $posts->map(fn ($post) => $post->title) uses arrow functions everywhere.
  • Query scopes and callbacks: ->where(fn ($q) => ...) in Eloquent Queries.
Recap

Key takeaways

  • Functions take parameters, do one job, and return a value.
  • Type every parameter and return: ?string allows null, int|float is a union, void returns nothing.
  • Default values make parameters optional; named arguments make calls readable.
  • ...$args collects many arguments, and ...$array spreads them back out.
  • Functions have their own scope; pass data in instead of reaching outside.
  • Closures and fn () => arrow functions let you pass behaviour around as a value.
