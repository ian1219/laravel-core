In one sentence

An array is one variable that holds many values, each stored under a key: either a number (a list) or a name (a map).

🗄️Think of a filing cabinet. In a numbered cabinet you grab "drawer 0, drawer 1, drawer 2". In a labelled cabinet you grab "the drawer marked title". Same cabinet, two ways of finding things.

Why it matters

Arrays are PHP's Swiss Army knife

📋

Real data comes in groups

A list of posts, a user's roles, the fields in a form. You rarely deal with just one value.

🔑

Key-value is everywhere

Config files, form input, JSON from an API and database rows all arrive as "name => value" pairs.

🔁

Loops do the heavy lifting

Once data is in an array, one foreach can process ten items or ten thousand with the same code.

Two shapes, one data type

Step by step

Build your array skills

We'll model a tiny blog as we go. Run each snippet with php arrays.php.

  1. Make a list (indexed array)

    Square brackets [] create an array. Items get numeric keys automatically, starting at 0. Use $array[] to push a new item onto the end.

    
          <?php

          $tags = ['php', 'laravel', 'tips'];

          echo $tags[0];          // php
          echo $tags[2];          // tips
          $tags[] = 'beginners';  // add to the end
          echo count($tags);      // 4

  2. Name your keys (associative array)

    An associative array uses keys you choose. The => arrow ("double arrow") links each key to its value. This is perfect for describing one thing with several properties.

    
          $post = [
              'title'     => 'Hello Laravel',
              'views'     => 1250,
              'published' => true,
          ];

          echo $post['title'];           // Hello Laravel
          $post['views']++;              // 1251
          $post['author'] = 'Ada';       // add a new key
          unset($post['published']);     // remove a key

          echo $post['subtitle'] ?? 'No subtitle';  // safe read of a missing key

    That trailing comma after the last item is allowed and recommended. It keeps future diffs clean.

  3. Nest arrays inside arrays

    Values can be arrays too. A list of maps is how you'll usually represent "many records", just like rows from a database.

    
          $posts = [
              ['title' => 'Hello Laravel', 'tags' => ['php', 'laravel']],
              ['title' => 'Arrays 101',    'tags' => ['php']],
          ];

          echo $posts[1]['title'];       // Arrays 101
          echo $posts[0]['tags'][1];     // laravel

  4. Loop with foreach

    foreach visits each item in turn. Ask for just the value, or for the key and value together.

    
          foreach ($posts as $post) {
              echo "📝 {$post['title']}" . PHP_EOL;
          }

          foreach ($post as $key => $value) {
              echo "{$key}: " . (is_array($value) ? implode(', ', $value) : $value) . PHP_EOL;
          }

  5. Use the built-in array functions

    PHP ships with dozens of array helpers. These few cover most day-to-day work. Each one returns a new array and leaves the original untouched.

    
          $prices = [10, 25, 40];

          in_array(25, $prices, true);                        // true (strict check)
          array_sum($prices);                                 // 75
          array_map(fn ($p) => $p * 2, $prices);              // [20, 50, 80]
          array_filter($prices, fn ($p) => $p > 20);          // [1 => 25, 2 => 40]
          array_keys($post);                                  // ['title', 'tags']
          array_key_exists('title', $post);                   // true
          implode(', ', ['php', 'laravel']);                  // "php, laravel"
          explode(',', 'a,b,c');                              // ['a', 'b', 'c']
    ℹ️ What's fn ($p) => ...?

    That's an arrow function: a tiny unnamed function. You'll learn it properly in Functions. For now read it as "for each $p, give back $p * 2".

  6. Unpack and merge: destructuring and spread

    Destructuring pulls values out of an array into variables in one line. The spread operator ... copies one array's items into another.

    
          [$first, $second] = ['php', 'laravel'];
          ['title' => $title, 'views' => $views] = ['title' => 'Hi', 'views' => 3];

          $defaults = ['theme' => 'light', 'perPage' => 10];
          $settings = [...$defaults, 'theme' => 'dark'];
          // ['theme' => 'dark', 'perPage' => 10]  (later keys win)
Common mistakes

Avoid this, do that

❌ Avoid

          $tags = ['php', 'laravel'];
          echo $tags[2];   // Warning: undefined key
          echo $tags[count($tags)];

Keys start at 0, so the last item is at count - 1, not count.

✅ Do

          echo $tags[array_key_last($tags)];
          echo $tags[5] ?? 'none';

Use array_key_last() for the last item, and ?? when a key might be missing.

❌ Avoid

          $user = ['Ada', 'ada@example.com', true];
          echo $user[1];   // which one was email?

A list of mixed meanings forces you to remember what each position means.

✅ Do

          $user = ['name' => 'Ada', 'email' => 'ada@example.com', 'isAdmin' => true];
          echo $user['email'];

When values describe one thing, name the keys. The code documents itself.

💡 Pro tip: print_r for a quick look

print_r($posts); prints a readable tree of any array. Wrap it as echo '<pre>' . print_r($posts, true) . '</pre>'; when viewing in a browser.

ℹ️ Where you'll see this in Laravel
  • Config files: every file in config/ simply returns an associative array (see Directory Structure).
  • Validation rules: ['title' => ['required', 'max:255']] is a map of lists (see Forms & Validation).
  • Passing data to views: view('posts.show', ['post' => $post]).
  • Collections: Laravel wraps arrays in a Collection object with friendlier map, filter and sum methods (see Eloquent Queries).
Recap

Key takeaways

  • Arrays use []; indexed arrays start counting at 0.
  • Associative arrays map named keys to values with =>.
  • Nest arrays to model lists of records.
  • foreach ($items as $key => $value) walks through every item.
  • array_map, array_filter, in_array, count and implode cover most needs.
  • Destructuring [$a, $b] = ... and spread [...$a] unpack and merge arrays.
