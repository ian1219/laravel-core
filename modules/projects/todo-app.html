What you'll build

A todo app where you can add, list, edit, complete and delete tasks: your first complete CRUD, built from an empty folder.

✅Every big app is lots of small CRUDs stitched together. Build this one end to end and you'll have practised the whole Laravel loop: route → controller → model → database → view.

Features

What the finished app does

Uses skills from Modules 01–06. No login yet; that comes in Project 2.

📝

Add tasks

A form with a title, optional notes and an optional due date.

📋

List tasks

Open tasks first, newest at the top, paginated 10 per page.

✔️

Mark as done

One click toggles a task between open and completed.

✏️

Edit & delete

Change a task or remove it, with a confirmation step.

🚦

Validation

Friendly error messages and old input kept when a form fails.

🔍

Filter

Show all, open or done tasks with a ?status= query string.

Build it

Build it milestone by milestone

Finish and test each milestone in the browser before moving on. Stuck? The chips link to the lesson that teaches that skill.

  1. Create the project

    Create a fresh app, choose no starter kit and SQLite as the database, then run it.

    
          laravel new todo-app
          cd todo-app
          composer run dev
    🚀 Installation & Setup 📁 Directory Structure

  2. Design the tasks table

    Generate a model with a migration, add the columns from the data model above, then run php artisan migrate.

    
          Schema::create('tasks', function (Blueprint $table) {
              $table->id();
              $table->string('title');
              $table->text('notes')->nullable();
              $table->date('due_on')->nullable();
              $table->timestamp('completed_at')->nullable();
              $table->timestamps();
          });
    🗄️ Migrations

  3. Build the Task model

    Set $fillable, add a casts() method for the dates, and an isDone() helper. Try it out in php artisan tinker.

    
          protected $fillable = ['title', 'notes', 'due_on', 'completed_at'];

          protected function casts(): array
          {
              return ['due_on' => 'date', 'completed_at' => 'datetime'];
          }

          public function isDone(): bool
          {
              return $this->completed_at !== null;
          }
    🧱 Models 🐘 Classes & Objects

  4. Wire up routes and a resource controller

    Generate TaskController with --resource, register it, and redirect / to the task list.

    
          Route::redirect('/', '/tasks');
          Route::resource('tasks', TaskController::class)->except('show');
          Route::patch('tasks/{task}/toggle', [TaskController::class, 'toggle'])
              ->name('tasks.toggle');
    🧭 Routing 🎛️ Controllers 🛠️ Resource Controllers

  5. Create a Blade layout

    Build layouts/app.blade.php with a header, a flash-message area and a {{ $slot }} or @yield('content'). Add Tailwind via the default Vite setup.

    🖌️ Blade Templates 🧩 The MVC Pattern

  6. List tasks and add new ones

    In index(), show open tasks first with pagination. Build the create form with @csrf and save in store().

    
          $tasks = Task::query()
              ->orderByRaw('completed_at is not null')
              ->latest()
              ->paginate(10);
    📋 Create & Read 🔎 Eloquent Queries

  7. Validate input properly

    Move rules into a TaskRequest Form Request: title required and max 255, due date a valid date not in the past. Show errors with @error and keep old() values.

    🚦 Forms & Validation 🌐 How HTTP Works

  8. Edit, toggle and delete

    Add the edit form with @method('PUT'), a delete button with @method('DELETE'), and a toggle() action that flips completed_at. Redirect back with a flash message each time.

    
          public function toggle(Task $task)
          {
              $task->update(['completed_at' => $task->isDone() ? null : now()]);

              return back()->with('status', 'Task updated.');
          }
    ✏️ Update & Delete 🔁 Request & Response

  9. Add a status filter

    Read ?status=open|done from the request and apply it with when(). Keep the filter in pagination links with withQueryString().

    
          $tasks = Task::query()
              ->when($request->status === 'open', fn ($q) => $q->whereNull('completed_at'))
              ->when($request->status === 'done', fn ($q) => $q->whereNotNull('completed_at'))
              ->latest()->paginate(10)->withQueryString();
    🔎 Eloquent Queries 🐘 Functions (arrow functions) 🐘 Arrays

Definition of done

You're finished when…

  • You can create, list, edit, toggle and delete tasks entirely in the browser.
  • Invalid forms show clear error messages and keep what the user typed.
  • All links use named routes, and php artisan route:list shows every route you expect.
  • Every form has @csrf, and updates/deletes use the right HTTP method.
  • Running php artisan migrate:fresh rebuilds the database from your migrations alone.
  • The project is committed to Git with a short README explaining how to run it.
