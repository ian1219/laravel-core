In one sentence

Blade lets you write ordinary HTML with a few smart placeholders and shortcuts, then turns it into a finished page full of your data.

📮Think of a mail-merge letter. You write the letter once with blanks like “Dear ___”, and Blade fills in the blanks for each reader, repeating sections (loops) and skipping paragraphs (conditions) as needed.

Why it matters

HTML without the mess

🛡️

Safe by default

{{ }} escapes output automatically, which blocks most cross-site scripting (XSS) attacks for free.

🧱

Write the layout once

Header, navigation and footer live in one layout. Every page just fills in its own content.

✨

Readable templates

@foreach and @if read like plain English, with no <?php ?> tags scattered through your HTML.

The big picture

How a page is assembled

Blade files end in .blade.php and live in resources/views. Laravel compiles them to plain PHP once and caches the result, so they're fast.

Step by step

Build the blog's templates

Assume the controller returns view('posts.index', ['posts' => $posts]), where each post has a title, excerpt and author.

  1. Echo data: {{ }} vs {!! !!}

    Double curly braces print a value and escape it, turning < into &lt; so any HTML or scripts inside show up as plain text. That's what you want 99% of the time.

    
          <h1>{{ $post->title }}</h1>
          <p>By {{ $post->author ?? 'Anonymous' }}</p>
          <p>Posted {{ $post->created_at->diffForHumans() }}</p>

          {{-- Blade comments never reach the browser --}}

          {!! $post->body_html !!}   {{-- raw, NOT escaped --}}
    ⚠️ {!! !!} is dangerous

    It prints raw HTML. If a user typed <script> into that field, it would run in every visitor's browser. Only use it for HTML you generated and trust. More in CSRF & XSS.

  2. Conditions and loops

    Blade directives start with @. @if shows or hides markup; @foreach repeats it. @forelse is a foreach with a built-in “nothing here” branch.

    
          @if (count($posts) > 10)
              <p>Wow, a busy blog!</p>
          @elseif (count($posts) === 0)
              <p>Quiet in here...</p>
          @endif

          @forelse ($posts as $post)
              <article>
                  <h2>{{ $post->title }}</h2>
                  <p>{{ $post->excerpt }}</p>
              </article>
          @empty
              <p>No posts yet. Write the first one!</p>
          @endforelse

    Other handy ones: @unless (if not), @isset, @auth / @guest (logged in or not).

  3. The $loop variable

    Inside any @foreach or @forelse, Blade gives you a free $loop object with information about where you are in the loop.

    
          @foreach ($posts as $post)
              <article class="{{ $loop->first ? 'featured' : '' }}">
                  <span>{{ $loop->iteration }} of {{ $loop->count }}</span>
                  <h2>{{ $post->title }}</h2>
              </article>

              @unless ($loop->last)
                  <hr>
              @endunless
          @endforeach
    $loop->iteration
    Current item number, starting at 1.
    $loop->index
    Current index, starting at 0.
    $loop->first / last
    true on the first or last item.
    $loop->count
    Total number of items.
    $loop->even / odd
    Handy for striped rows.

  4. Layouts, the classic way: @extends, @section, @yield

    A layout is the shared page frame. It marks holes with @yield; each page says which layout it @extends and fills the holes with @section.

    
          <!doctype html>
          <html lang="en">
          <head>
              <title>@yield('title', 'My Blog')</title>
          </head>
          <body>
              <nav><a href="{{ route('posts.index') }}">Blog</a></nav>
              <main>
                  @yield('content')
              </main>
          </body>
          </html>
        
    
          @extends('layouts.app')

          @section('title', 'All posts')

          @section('content')
              <h1>All posts</h1>
              {{-- the @forelse loop from step 2 --}}
          @endsection

    Pull small shared snippets into any view with @include. You can pass extra data as a second argument:

    
          @include('partials.alert', ['type' => 'success'])
          {{-- loads resources/views/partials/alert.blade.php --}}

  5. Layouts, the modern way: components and {{ $slot }}

    Newer Laravel apps and starter kits use components. Any file in resources/views/components becomes an HTML-like tag with an x- prefix. Whatever you put between the tags lands in {{ $slot }}.

    
          @props(['title' => 'My Blog'])

          <!doctype html>
          <html lang="en">
          <head><title>{{ $title }}</title></head>
          <body>
              <nav><a href="{{ route('posts.index') }}">Blog</a></nav>
              <main>
                  {{ $slot }}
              </main>
          </body>
          </html>
        
    
          <x-layout title="All posts">
              <h1>All posts</h1>

              @foreach ($posts as $post)
                  <x-post-card :post="$post" />
              @endforeach
          </x-layout>

    @props declares the attributes a component accepts. A colon (:post) passes a PHP value instead of a plain string. Which style should you use? Both work; components are the modern default, but you'll see @extends in plenty of existing projects.

  6. Forms need @csrf

    Every POST, PUT, PATCH or DELETE form in web.php routes must include a CSRF token, a hidden secret proving the form came from your site. Forget it and you'll get a 419 Page Expired error.

    
          <form method="POST" action="{{ route('posts.store') }}">
              @csrf
              <input name="title" value="{{ old('title') }}">
              <button>Publish</button>
          </form>

          <form method="POST" action="{{ route('posts.destroy', $post) }}">
              @csrf
              @method('DELETE')
              <button>Delete</button>
          </form>

    HTML forms can only send GET and POST, so @method('DELETE') adds a hidden field telling Laravel which verb you really meant.

Common mistakes

Avoid this, do that

❌ Avoid

          <p>{!! $comment->body !!}</p>

User-written content printed raw is an open door for XSS attacks.

✅ Do

          <p>{{ $comment->body }}</p>

Escape by default. Reach for {!! !!} only for trusted, already-sanitised HTML.

❌ Avoid

          @if (count($posts))
              @foreach ($posts as $post) ... @endforeach
          @else
              <p>No posts.</p>
          @endif

An @if wrapped around a @foreach is more nesting than you need.

✅ Do

          @forelse ($posts as $post)
              ...
          @empty
              <p>No posts.</p>
          @endforelse

@forelse handles the empty case in one tidy block.

💡 Pro tip: generate components

php artisan make:component PostCard --view creates an anonymous component at resources/views/components/post-card.blade.php, ready to use as <x-post-card />.

🏋️ Try it yourself
  1. Create a components/layout.blade.php with a nav bar and {{ $slot }}, and use it from posts/index.blade.php.
  2. Render your fake posts with @forelse, showing “No posts yet” when the array is empty.
  3. Number each post with $loop->iteration and add a “featured” class to the first one.
  4. Pass a title containing <b>bold</b> and compare how {{ }} and {!! !!} display it.
  5. Build a small form with @csrf, then remove it and submit to see the 419 error.
Recap

Key takeaways

  • {{ $value }} prints escaped output; {!! $value !!} prints raw HTML, so use it with care.
  • @if, @foreach and @forelse/@empty control what's shown.
  • $loop gives you iteration, first, last, count and more inside loops.
  • Layouts: @extends + @section + @yield, or components with <x-layout> + {{ $slot }}.
  • @include pulls in partials; every non-GET form needs @csrf.
